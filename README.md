This repository containts a series of jupyter notebooks containing mini projects done for a course on ML and AI for biochemistry/biophysics.

Files in this repository 
Guess_Who_Clare_Morris - Coding a guess who game using data generated by all the classmates! 

Act1_PLMs - Notebook containing exercises to become familiar with protein embeddings and working with the data contained in them to find similarities in proteomes of different organisms (data was sourced from Uniprot)

Act2
Module 2 - Notebooks with exercises to train a basic ML regression models using scikit learn. We used the class data from the first guess who game to predict characteristics of people based on that data. Learned different scoring metrics and how to evaluate the ML model performance. 
Module 2B - Took the methods we learned above and applied it to a "real" dataset that contained training data on steroid-interacting proteins. Trained different regression models to predict whether a protein interacts with steroids, evaluated model performance. 

Act3
Trained a ML model to predict molecular properties on a small molecule dataset.Used RDKit to represent molecules in 2D and 3D images and calculate molecular fingerprints and trained an ML model to predict solubility. 
Used pytorch to build a simple GNN. 

Act4 - Intro to diffusion models using simple images, and protein structure prediction and de novo design using RFDiffusion.
